# เว็บไซต์สำนักบริหารทรัพยากรบุคคล (สบท.)

Astro + SQLite รันบน Node.js มีหลังบ้านในตัวที่ `/admin` (เขียนเองในโปรเจกต์นี้ ไม่ใช้ EmDash แล้ว)

- ติดตั้งบน server: ดู [DEPLOY-IT.md](DEPLOY-IT.md)
- บันทึกการเปลี่ยนแปลง: [CHANGELOG.md](CHANGELOG.md)
- โครงสร้างโค้ด: [AGENTS.md](AGENTS.md)

```bash
npm install
npm run dev     # http://localhost:4321  หลังบ้าน http://localhost:4321/admin
```
